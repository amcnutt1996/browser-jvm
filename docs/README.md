The runner was built inside [gregOS](https://github.com/amcnutt1996/gregOS)
and then moved here, so these documents use gregOS paths. In this
repository:

| Path in the documents | Path here |
| --- | --- |
| `components/apps/JavaRunner/jvm/` | `src/jvm/` |
| `components/apps/JavaRunner/gdx/` | `src/gdx/` |
| `components/apps/JavaRunner/java/` | `java/` |
| `public/System/JavaRunner/` | `jars/` |
| `__tests__/components/apps/JavaRunner/` | `test/` |
| `scripts/javaRunner/` | `scripts/` |
| `docs/java-runner/` | `docs/` |

The gregOS app shell (`components/apps/JavaRunner/*.ts(x)`: the window,
worker and file-system bridge) and the Playwright playthrough
(`scripts/javaRunner/shattered.cjs`) stay in gregOS.
